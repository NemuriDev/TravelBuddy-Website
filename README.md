# TravelBuddy

TravelBuddy is a web-based information system for discovering eco-tourism destinations in Bulacan.

The website allows visitors to browse destinations and view information about different places. Registered users can create an account, log in, and manage their profile.

The project was created as part of our IT coursework to practice developing a website using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

* User registration and login
* User logout
* User profile
* Destination browsing
* Destination information
* Contact page
* Responsive design
* MySQL database
* PHP session-based authentication

## Technologies

## Project Description

TravelBuddy focuses on eco-tourism destinations in Bulacan and provides users with a simple way to look through destination information.

The system is being developed with PHP and MySQL for the backend, while HTML, CSS, and JavaScript are used for the website interface and interactions.
